# 概念系统的重构

1. 重构前提：概念所指代的内容比概念本身更加重要，概念的重构实质是对内容做归属划分，重构概念的前提是需要对内容本身有清晰的了解。
    
2. 重构原因：自然语言也是一门语言，用编程语言构建的概念系统需要重构，自然语言更需要重构。概念是真理的篮子，当先驱试图描述其发现的客观规律时，就提出一个概念来描述这个规律，并未考虑概念系统的发展性，结果就是后来者维整个概念系统的成本越来越高，并且随着概念系统的发展，整个概念体系会成为复杂的网状结构！如果用计算机领域的词汇来说，概念系统的耦合性太高，会导致**记忆概念、使用概念、更新概念**的成本非常大，严重阻碍了社会网络的整体学习速率，此刻就到了要做概念重构的时刻了。
    

# 概念系统的评估 → 七度标准

基于辩证法的七度评价体系用来评估内容质量的好坏，任何知识传播类材料从这7个角度去优化，总有相当大的优化的空间。准度永远是知识传播类材料最低的要求！好的概念系统应该如同辩证法一样简洁、优雅，系统。

|七度评价|重要性|辩证法概念|优化方式| |-|-|-|-| |准度|内容的正确性|真理|参考资料| |精度|内容的针对性 → 对用户有用|价值|用户调研| |深度|内容的深度性|两点论 |树 → MECE | |广宽|内容的全面性||| |亮度|主次清晰|重点论|核心线索| |梯度|阶梯性 → 循循善诱|发展性 |DAG → 拓扑排序不唯一，每种排序方式需要根据目标用户精细化| |高度|扩展性 → 高屋建瓴||维护一套可发展的概念体系|

# 重构的理论基础 → 树型结构

## 哲学基础：对立统一

> **唯物辩证法认为，矛盾是普遍存在的，矛盾是事物内部及事物之间既对立又统一的两个方面，即辩证统一**的。**对立**指矛盾双方相互排斥、相互斗争的关系；**统一**指矛盾双方相互依存，一方的存在以另一方为前提。 相互排斥体现的是斗争的一面，相互依存体现的是**统一**的一面。

## 分类原则：MECE

> MECE指的是兄弟结点指代的内容是相互独立，并且能够完全穷尽父节点的信息。

|优点|解释| |-|-| |清晰|子概念相互独立| |全面|子概念穷尽父概念| |深度|无限往下分类| |创新|无法穷尽的地方就是新的领域|

## 数据结构：树与表

1. 树：主干分类
    
2. 深度：树的深度不要太深，太深的叶结点无太多信息量。
    
3. 宽度：树形结构的单节点的孩子结点的数量控制在4~5个左右，孩子结点数量太多，存在冗余
    
4. 表：多重分类
    
5. 树形结构只是对内容的某一个维度做对比，表格可以对内容的多个维度做对比

3. 分解方式：从多个角度去分解内容所拥有的属性

## 节点扩散

4. 扩散启发：不存在孤立的事物，任意事物都处于普遍联系之中，举个算法中的例子，当我们接触到时间复杂度这个概念的时候，那么一定会有空间复杂度，否则发明概念的人根本不会称其为时间复杂度，而是称其为复杂度。概念本身含有的信息量是足够多的。
    
5. 扩散方向
    
6. 横向扩散：兄弟节点
    
7. 向下扩散：孩子节点
    
8. 向上扩散：父亲节点
    
9. 扩散依据：分解的属性
