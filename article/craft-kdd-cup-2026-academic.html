TAAC × KDD Cup 2026 学术赛道冠军 lozyyeah CRAFT · Feature Transport

意图背包是怎么吃进数据、又怎么一层层更新的

单页讲解：赛题真实字段 → tokenize → $I^{(0)}$ 初始化 → 每层四拍更新 → 用 $I^{(L)}$ 打 CVR。公式用 KaTeX 渲染。

先说清楚：哪些是公开事实，哪些是复原

队伍 lozyyeah 拿下学术赛道第一，奖金 30 万美元。方法名 CRAFT：把重点从 Feature Interaction 转到 Feature Transport。Intent Token 是跨层载体（媒体称为「意图背包」）。

冠军方案没有公开论文和官方 AUC。下面公式是按 workshop / 媒体描述 + UNI-REC 官方 schema / HyFormer 基线习惯复原的，不是 arXiv 原式。工业冠军 QueryFormer 的 AUC +0.0048 不是这套模型的成绩。

1. 一行样本里到底有多少数据

初赛量级：约 2 亿 用户序列样本（官方介绍）。Demo 是 1000 行、120 列的扁平 Parquet。预测目标是广告 CVR（点后转化），指标 AUC，且有推理时延上限。

区块列数是什么进 Intent 的角色
ID / label / timestamp 5 样本键、标签、请求时间 训练监督；时间可做成周期特征进 NS
user_int 46 35 个标量 + 11 个多值数组（画像、偏好等） NS → 控制信号（怎么读）
user_dense 10 浮点数组；含 embedding 类（如 61、87）及与 int 对齐的 62–66、89–91 NS → 控制信号（怎么读）
item_int（广告） 14 类目、类型、多标签等 NS → 控制信号（面对哪条广告）

序列截断（基线常见，非 CRAFT 官方超参）：$L_a=L_b=256$，$L_c=L_d=512$。每步是该域多列 id 拼起来的一条事件，不是一个 int。

2. Tokenize：数据如何变成三类张量

非序列 NS（人 + 货）

稀疏 id：$e(v)=E[v]\in\mathbb{R}^{d_e}$。基线 RankMixer 常把 user 压成 $K_u=5$ 个 token、item 压成 $K_a=2$ 个。Dense 再投影成额外 NS token（也可分组 gate 融成 1 个 user dense token）。

$$ Z^{\mathrm{NS}} = \bigl[U_{\text{user int/dense}};\ A_{\text{ad}}\bigr] \in \mathbb{R}^{N\times d} $$

$N$ 很小（几个到十几个），这是控制，不是背包本体。

序列（四个域独立）

$$ s^{(m)}_t = W^{(m)}\,\mathrm{Concat}(\text{该步各列 embedding},\ \tau_t),\quad H^{(m)}=\mathrm{Enc}^{(m)}(S^{(m)}) \in \mathbb{R}^{L_m\times d} $$

$m\in\{a,b,c,d\}$。这是素材，一步一个 token，很长。

Intent 初值（公开未给出精确式；与「浅层就用人×货管背包」最贴的写法）

$$ I^{(0)} = W_0\,\mathrm{Pool}(Z^{\mathrm{NS}}) + b_0 \in \mathbb{R}^{K_I\times d} $$

$K_I$ 很小（1 或少数个）。此时背包 ≈「这个用户看这条广告」的先验。45 列序列通常还没写进去。也可以加可学习 $I_{\mathrm{learn}}$，但纯 0 向量当锚点不合理：拉回时会丢掉人×货条件。

3. 背包如何逐步更新（一层四拍）

状态：$I^{(\ell)}\to I^{(\ell+1)}$。同一条短向量走 $L$ 层，不是每层新建。

1
只出规则：46+10+14 这些 NS 汇总成控制 $$c^{(\ell)}=\mathrm{Pool}(Z^{\mathrm{NS},(\ell)})$$ $$\gamma^{(\ell)},\beta^{(\ell)},g^{(\ell)}=\mathrm{MLP}(c^{(\ell)})$$ 这一拍不把某个点击写进 $I$。User+Ad 告诉模型：该把意图拧向哪、这层更新可不可信。
2
Transport：搬家 + 可撤销 $$\widetilde{I}=(1+\gamma^{(\ell)})\odot I^{(\ell)}+\beta^{(\ell)}$$ $$I^{\leftarrow}=g^{(\ell)}\,\widetilde{I}+(1-g^{(\ell)})\,I^{(0)}$$ $g\to 1$ 接受本层；$g\to 0$ 拉回 $I^{(0)}$，避免深层把意图冲掉。序列 $H$ 往往同步 FiLM。
3
写入证据：四域序列被当前 Intent 检索 $$\Delta I=\mathrm{CrossAttn}(Q=I^{\leftarrow},\ K=V=H^{\leftarrow})$$ $$I^{\mathrm{tr}}=I^{\leftarrow}+\Delta I$$ 注意力大的那些步（例如同类广告、近期转化）进入 $\Delta I$。残差累加：旧结论还在。这是序列唯一把内容装进背包的主路径。
4
Interaction：再和 NS 细交叉，交给下一层 $$I^{(\ell+1)},H^{(\ell+1)},Z^{\mathrm{NS},(\ell+1)}=\mathrm{Mix}(I^{\mathrm{tr}},H^{\leftarrow},Z^{\mathrm{NS}})$$ Mix = Cross-Attention / RankMixer 等。顺序必须是 Transport 在前、Interaction 在后。

一层合写：

$$ I^{(\ell+1)}=\mathcal{U}\bigl(I^{(\ell)};\,Z^{\mathrm{NS}},\,H,\,I^{(0)}\bigr) $$
I^(0) [仅 User×Ad 先验] → 层1: 控制(NS) → 拉回/推空间 → CrossAttn(seq_a..d) → Mix → I^(1) → 层2: Query 已是 I^(1)，再去抠上一层没对齐的行为 → … → I^(L) → MLP → CVR

4. 三路数据分别贡献什么

数据张量更新通道若去掉会怎样
user_int + user_dense 部分 $Z^{\mathrm{NS}}$ $\gamma,\beta,g$ 与 Mix 不知道「谁」，控制与交叉都缺人侧
item_int（广告） 部分 $Z^{\mathrm{NS}}$ 同上；决定检索哪种意图 序列无法按「当前广告」对齐
seq_a…d 共 45 列、最长数百步 $H$ $\Delta I$ 残差写入 背包停在先验，没有行为证据
$I^{(0)}$ 短 token $(1-g)I^{(0)}$ 锚点 深层无法把冲淡的意图拉回来

预测：

$$ \hat{y}=\sigma\bigl(\mathrm{MLP}(\mathrm{Pool}(I^{(L)}))\bigr) $$ 报道强调不用多层后已衰减的原始序列池化当主表征。
