# More Agents Is All You Need - Emergent Collaboration in LLM Agents

## 核心问题

增加多个 agent 是否一定提升表现？多 agent improvement 来自真正协作，还是样本多样性和投票效应？

## 内容

论文研究多 agent sampling / debate / collaboration 带来的性能变化，为 multi-agent 方法提供经验依据。

## 为什么重要

做 multi-agent research workflow 时不能只说“多个角色更好”，需要证明角色分工、通信协议或验证机制带来了增益。
