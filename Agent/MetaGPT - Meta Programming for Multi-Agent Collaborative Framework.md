# MetaGPT - Meta Programming for Multi-Agent Collaborative Framework

## 核心问题

多 agent 协作容易混乱，需要标准化角色、流程和中间产物。

## 系统设计

MetaGPT 把软件公司流程映射成多 agent SOP，例如产品经理、架构师、工程师、测试等角色协作。

## 为什么重要

它展示了 multi-agent workflow 的一种工程化路线。对 research agent，可以类比为 searcher、reader、verifier、writer、editor 的 SOP。
