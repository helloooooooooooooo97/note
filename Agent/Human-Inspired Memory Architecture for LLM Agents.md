# Human-Inspired Memory Architecture for LLM Agents

## 核心问题

朴素 memory accumulation 会造成噪声、冲突和检索膨胀。能否借鉴人类记忆机制设计 agent memory？

## 方法

论文提出 sleep-phase consolidation、interference-based forgetting、engram maturation、reconsolidation、entity knowledge graph、multi-cue retrieval 等机制。

## 为什么重要

这篇适合启发“可遗忘、可整合、可再巩固”的 research memory，而不是无限追加 Obsidian 笔记。
