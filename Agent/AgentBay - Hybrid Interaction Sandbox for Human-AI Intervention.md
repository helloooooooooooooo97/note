# AgentBay - Hybrid Interaction Sandbox for Human-AI Intervention

## 核心问题

Agent 在真实复杂任务中会遇到异常，需要人类无缝接管、修正或指导。

## 关键贡献

- 提出 hybrid interaction sandbox。
- 支持 Agent + Human 共同完成复杂任务。
- 关注 mission-critical 应用中的 human intervention。

## 对低显卡选题的启发

适合研究“可接管 research agent”：当来源冲突、网页登录、引用不确定时，系统怎样把控制权交给人。
