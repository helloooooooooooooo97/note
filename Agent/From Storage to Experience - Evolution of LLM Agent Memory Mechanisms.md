# From Storage to Experience - Evolution of LLM Agent Memory Mechanisms

## 核心问题

很多 agent memory 只停留在“存储历史”，但长期 agent 真正需要的是把轨迹变成可迁移经验。

## 内容

论文提出 Storage -> Reflection -> Experience 的演化框架：先保存轨迹，再反思加工，最后抽象为可复用经验。

## 为什么重要

这个框架很适合做 research agent：从“保存查过的网页”进化到“学会什么来源可信、哪些查询策略有效、哪些错误会反复出现”。
