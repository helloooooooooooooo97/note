# AgentProp-Bench - Propagation Cascades in Tool-Using Agents

## 核心问题

Tool-using agent 的自动评估常默认 judge 可靠，但这个假设本身需要验证。错误还会沿着工具调用链传播。

## 关键贡献

- 2,000 任务、2,300 traces 的 tool-agent benchmark。
- 包含 human-validated subset。
- 研究 judge reliability、propagation cascades 和 runtime mitigation。
