# FlowSteer - Interactive Agentic Workflow Orchestration

## 核心问题

用户需要能看见、编辑和引导 agent workflow，而不是把所有控制权交给黑箱 planner。

## 方法

FlowSteer 关注交互式 workflow orchestration，用可执行画布和用户 steering 方式控制 agent 流程。

## 为什么重要

这非常适合 human-agent interaction：研究 agent 什么时候应自动执行，什么时候应把流程展示给用户确认。
