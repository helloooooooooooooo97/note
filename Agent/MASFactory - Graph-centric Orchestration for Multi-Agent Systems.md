# MASFactory - Graph-centric Orchestration for Multi-Agent Systems

## 核心问题

多 agent workflow 如果只用自然语言描述，很难编辑、调试、复现和审计。

## 方法

MASFactory 使用 graph-centric orchestration，把自然语言 intent 编译成可编辑 workflow specification，再变成可执行图。

## 为什么重要

这与 Obsidian research workflow 很契合：可以把研究任务拆成显式 DAG，便于检查每步证据和产物。
