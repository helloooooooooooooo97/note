# APWA - Distributed Architecture for Parallelizable Agentic Workflows

## 核心问题

Agent workflow 越来越复杂，瓶颈从单模型能力转向系统级 orchestration 和并行执行。

## 方法

APWA 把 agentic workflows 类比 MapReduce / Spark，提出面向可并行 agent 工作流的分布式架构。

## 为什么重要

适合系统方向阅读。对你来说，可以简化为“research workflow 中哪些步骤能并行，哪些必须顺序验证”。
