# Evaluation and Benchmarking of LLM Agents - A Survey

## 核心问题

Agent evaluation 既要问“评什么”，也要问“怎么评”。这篇 survey 用 evaluation objectives 和 evaluation process 两个轴整理领域。

## 关键贡献

- 按 behavior、capabilities、reliability、safety 等目标分类。
- 按 interaction modes、datasets、metrics、tooling 等过程分类。

## 对低显卡选题的启发

这篇可以帮你把选题包装成“reliability + evidence-grounded evaluation + real-world web environment”的交叉贡献。
