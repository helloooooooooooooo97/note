# ChatDev - Communicative Agents for Software Development

## 核心问题

LLM agents 能否通过角色扮演和自然语言沟通，模拟软件公司完成开发流程？

## 系统设计

ChatDev 把开发过程拆为设计、编码、测试、文档等阶段，并让多个角色 agent 通过 chat chain 协作。

## 为什么重要

它是 multi-agent software engineering 的代表系统，也暴露了通信冗余、错误传播、角色失效等问题。
