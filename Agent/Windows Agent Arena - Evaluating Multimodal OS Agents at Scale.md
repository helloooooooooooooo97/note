# Windows Agent Arena - Evaluating Multimodal OS Agents at Scale

## 核心问题

OS agent 的评估很慢、环境复杂、任务多模态。Windows Agent Arena 在真实 Windows OS 中评估 agent。

## 关键贡献

- 可复现的 Windows OS 环境。
- 150+ 多领域任务。
- 关注规划、屏幕理解和工具使用。

## 对低显卡选题的启发

对你来说，完整 OS benchmark 可能太重，但可以缩成“Obsidian + Browser + PDF”的研究工作台环境。
