# The Hallucination Leaderboard - LLM Tool Hallucination

## 核心问题

Tool-use agent 的 hallucination 不只体现在事实错误，还会体现在虚构工具、虚构参数、虚构引用和虚构执行结果。

## 内容

论文提出开放 hallucination 测量努力，虽不是专门 agent 论文，但对 agent 引用可靠性和工具幻觉分析有参考价值。

## 为什么重要

Research agent 最大风险之一就是“看起来查过，但引用或结论不被来源支持”。这个方向可以和 evidence-aware verification 结合。
