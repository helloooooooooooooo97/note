# Single-Agent LLMs Outperform Multi-Agent Systems under Equal Thinking Budgets

## 核心问题

多 agent 是否真的优于单 agent？如果给相同 thinking token budget，优势还存在吗？

## 内容

论文比较 single-agent 与 multi-agent systems 在 multi-hop reasoning 下的表现，强调 coordination cost 可能抵消多 agent 收益。

## 为什么重要

这篇对 multi-agent 选题很关键：不能假设多 agent 一定更好，必须证明协调机制的收益大于通信和冗余成本。
