# AOrchestra - Automating Sub-Agent Creation for Agentic Orchestration

## 核心问题

Multi-agent 系统通常需要人工设计子 agent。能否自动创建适合任务的 sub-agents？

## 方法

AOrchestra 把 agent 表示成 Instruction、Context、Tools、Model 的四元组，并自动生成/组合 sub-agents。

## 为什么重要

Research agent 中，系统可以根据任务自动拆出“论文筛选员”“引用验证员”“frontmatter 检查员”等角色。
