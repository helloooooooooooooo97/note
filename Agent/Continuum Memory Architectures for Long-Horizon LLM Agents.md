# Continuum Memory Architectures for Long-Horizon LLM Agents

## 核心问题

长期 agent 需要连续管理不同粒度的记忆，而不是只在短上下文和长期向量库之间二选一。

## 方法

论文围绕 long-horizon agent memory architecture 展开，强调多层、连续的记忆组织方式。

## 为什么重要

适合放在 memory architecture 谱系里，与 MemexRL、AMA-Bench、AgeMem 一起读。
