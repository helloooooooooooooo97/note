# BrowserGym - Gym Environment for Web Agents

## 核心问题

Web agent 研究需要标准化环境接口，方便训练、评测和复现。

## 系统设计

BrowserGym 提供类似 Gym 的 web task environment，与 WorkArena 关联，支持 web navigation agent 的开发和评测。

## 为什么重要

它提示你：如果做 research agent benchmark，最好不仅有数据，还要有 environment API。
