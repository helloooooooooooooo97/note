# Robust Semi-Supervised Temporal Intrusion Detection for Adversarial Cloud Networks

## 核心问题

云网络流量有时间漂移，无标签数据还可能被对抗污染。普通半监督 NIDS 容易把污染样本学进去。

## 方法

论文提出 robust semi-supervised temporal learning framework，显式处理 adversarial contamination 和 temporal drift。

## 适合的矩阵位置

- 弱/半监督 × flow。
