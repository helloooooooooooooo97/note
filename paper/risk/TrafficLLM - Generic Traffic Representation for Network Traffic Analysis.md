# TrafficLLM - Generic Traffic Representation for Network Traffic Analysis

## 核心问题

LLM 不能直接理解原始流量特征，需要把 traffic 转成适合语言模型处理的表示。

## 方法

TrafficLLM 提出 generic traffic representation，用于增强 LLM 在网络流量分析和威胁检测中的能力。

## 适合的矩阵位置

- 大模型 × flow。
