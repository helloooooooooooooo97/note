# Experiential Reflective Learning for Self-Improving LLM Agents

## 核心问题

Agent 失败之后如何把单次经验转化为可迁移启发，而不是只记录一次失败日志？

## 方法

Experiential Reflective Learning 让 agent 从 past task trajectories 中提炼 transferable heuristics，并在后续任务中检索使用。

## 为什么重要

这是 Reflexion 的 2026 延续方向。对 research agent，可以让系统从“引用错误”“检索漏项”“frontmatter 格式错”中总结可复用规则。
