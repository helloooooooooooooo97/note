# When Agents Fail to Act - Tool Invocation Reliability in Multi-Agent Systems

## 核心问题

Multi-agent 系统里，失败不一定是推理错，也可能是该调用工具时没调用、调用错工具或跨 agent 责任分配错。

## 关键贡献

- 面向企业 multi-agent 的 tool invocation reliability 诊断框架。
- 12 类错误 taxonomy。
- 讨论可靠性阈值和模型选择。

## 对低显卡选题的启发

可以把多 agent 文献综述系统拆成 searcher/reader/verifier/writer，分析每个角色的 tool invocation failure。
