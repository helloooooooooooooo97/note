# Memory for Autonomous LLM Agents - Mechanisms Evaluation and Frontiers

## 核心问题

Agent memory 已经从简单向量库变成独立研究问题：写入、管理、读取、遗忘、冲突处理、隐私和延迟都影响长期 agent 的可靠性。

## 内容

这篇 survey 按机制、评估和应用整理 2022 到 2026 初的 agent memory 研究，覆盖 context compression、retrieval stores、reflective self-improvement、hierarchical virtual context、policy-learned memory management。

## 为什么重要

适合作为 memory mechanism 的 2026 综述入口。对你的 research agent 方向，尤其值得关注 evidence-preserving memory、contradiction handling 和 learned forgetting。
