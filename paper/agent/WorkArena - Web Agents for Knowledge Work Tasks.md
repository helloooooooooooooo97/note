# WorkArena - Web Agents for Knowledge Work Tasks

## 核心问题

Web agent 是否能完成企业知识工作任务，而不是只在玩具网页上点击按钮？

## 关键贡献

- 基于 ServiceNow 的远程托管 benchmark。
- 任务面向企业知识工作。
- 同时推出 BrowserGym 环境，便于开发和评估 web agents。

## 对低显卡选题的启发

如果你做香港 research agent，可以借鉴 WorkArena 的“真实工作软件 + 可复现任务 + 远程环境”路线。
