# The AI Scientist - Automated Open-Ended Scientific Discovery

## 核心问题

AI agent 能否从想法生成、实验、写作到评审，自动完成一轮科研流程？

## 系统设计

系统让 LLM agent 生成研究想法、编写和运行实验代码、整理结果、写论文，并使用自动 reviewer 评分。

## 为什么重要

它是 research agent 的标志性应用论文。低显卡方向可以聚焦其中一个薄弱环节：文献核验、实验复现、引用可靠性、自动 reviewer 偏差。
