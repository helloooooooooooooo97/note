# Orla - Serving LLM-Based Multi-Agent Systems

## 核心问题

Multi-agent systems 不只是 prompt engineering，也涉及模型服务、调度、缓存、资源分配和上下文管理。

## 方法

Orla 提供 stage mapper、workflow orchestrator、memory manager 等组件，优化多 agent workflow 的延迟和成本。

## 为什么重要

如果将来你做系统论文，Orla 提醒你：agent runtime 的 KV cache、stage routing 和 serving cost 也可以成为贡献点。
