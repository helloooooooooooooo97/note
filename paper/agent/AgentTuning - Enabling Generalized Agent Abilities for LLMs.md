# AgentTuning - Enabling Generalized Agent Abilities for LLMs

## 核心问题

能否通过混合多环境 agent 数据，让开源 LLM 获得更通用的 agent 能力？

## 方法

AgentTuning 收集多领域 agent 轨迹，进行指令微调，并评估模型在未见 agent 任务上的泛化。

## 为什么重要

这是 agent finetuning 的代表路线。低显卡条件下可以研究数据选择、轨迹质量和小模型 LoRA，而不必训练大模型。
