# AgeMem - Unified Short-Term and Long-Term Memory for Agents

## 核心问题

Agent memory 往往把短期上下文和长期记忆割裂开，导致记忆更新、遗忘和检索策略不一致。

## 方法

AgeMem 将短期和长期记忆管理整合进 agent policy，通过工具化动作管理 memory。

## 为什么重要

对 research agent 来说，一个很自然的问题是：哪些信息应该留在当前任务上下文，哪些应该沉淀为长期经验？
