# Data Interpreter - An LLM Agent For Data Science

## 核心问题

数据科学任务往往需要理解数据、写代码、调试、画图和解释结果，单轮代码生成不够。

## 系统设计

Data Interpreter 强调动态规划、工具集成和执行反馈，用 agent 完成数据分析、机器学习和数学任务。

## 为什么重要

这是 data analysis agent 的强应用论文。Research agent 可以借鉴其“代码执行反馈 + 动态计划调整”。
