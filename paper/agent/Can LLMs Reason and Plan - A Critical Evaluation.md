# Can LLMs Reason and Plan - A Critical Evaluation

## 核心问题

LLM 在规划任务上的成功，到底是泛化规划能力，还是依赖语言模式和任务泄漏？

## 内容

论文从经典 planning problem 出发，批判性评估 LLM 规划能力，提醒研究者不要把流畅输出等同于可靠规划。

## 为什么重要

如果你做 agent planning 方法，需要用这类机制分析论文约束叙事：agent 的 planning 需要外部验证和执行反馈。
