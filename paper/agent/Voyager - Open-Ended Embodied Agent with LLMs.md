# Voyager - Open-Ended Embodied Agent with LLMs

## 核心问题

开放世界环境中，agent 如何自主探索、积累技能并长期改进？

## 系统设计

Voyager 在 Minecraft 中结合 automatic curriculum、skill library 和 iterative prompting。技能库是它最有启发的 memory mechanism。

## 为什么重要

Research agent 也可以有 skill library：如何搜索官网、如何核对负责人、如何写 paper card、如何检查 frontmatter。
