# Graph of Thoughts - Solving Elaborate Problems with LLMs

## 核心问题

Tree 结构仍然限制思路之间的合并、复用和聚合。复杂 agent 任务经常需要把多个中间结果组合成图。

## 方法

Graph of Thoughts 把 LLM 生成的中间信息建成图，支持 split、aggregate、refine 等操作。

## 为什么重要

Research agent 的证据组织天然是图：论文、作者、机构、claim、source、冲突证据之间有关系。
