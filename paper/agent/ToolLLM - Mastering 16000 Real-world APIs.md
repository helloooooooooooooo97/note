# ToolLLM - Mastering 16000 Real-world APIs

## 核心问题

真实世界 API 数量巨大、文档复杂，agent 需要泛化到多领域工具调用。

## 方法

ToolLLM 构建 ToolBench，覆盖 RapidAPI 上的大量真实 API，并训练工具调用模型。

## 为什么重要

它把 tool learning 从少量固定工具扩展到大规模 API 生态。对 research agent 来说，可以迁移为“学会调用搜索、网页、PDF、文件系统、引用检查器”等工具。
