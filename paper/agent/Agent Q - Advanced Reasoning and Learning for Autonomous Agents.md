# Agent Q - Advanced Reasoning and Learning for Autonomous Agents

## 核心问题

Autonomous agent 在动态网页/交易环境中需要从交互经验中学习，静态 SFT 不够。

## 方法

Agent Q 结合搜索、self-critique 和偏好/强化学习思路，在真实 booking 等场景中提升 agent 成功率。

## 为什么重要

它代表“planning + self-critique + learning from interaction”的训练型 agent 路线。可以作为方法启发，但完整训练不适合低显卡。
