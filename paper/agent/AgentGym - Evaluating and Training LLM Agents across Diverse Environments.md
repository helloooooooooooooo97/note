# AgentGym - Evaluating and Training LLM Agents across Diverse Environments

## 核心问题

通用 agent 不能只在单一环境中训练或评估，需要跨多环境、多任务学习和自我演化。

## 方法

AgentGym 提供多环境 agent 训练/评估框架，并提出 AgentEvol 探索 agent self-evolution。

## 为什么重要

这是 agent training 谱系的重要论文。对低显卡选题，更适合作为对照背景，而不是直接复现完整训练。
