# Utility-Guided Agent Orchestration for Efficient LLM Tool Use

## 核心问题

Tool-using agents 面临质量和成本的张力：多调用工具可能更准，但延迟和费用更高。

## 方法

论文把 agent orchestration 显式建模为 utility decision problem，用轻量 utility 设计控制工具使用。

## 为什么重要

这很适合低显卡方法论文：不用训练大模型，只要提出更好的工具调用控制策略并严谨评测。
