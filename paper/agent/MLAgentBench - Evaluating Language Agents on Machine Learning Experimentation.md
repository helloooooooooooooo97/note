# MLAgentBench - Evaluating Language Agents on Machine Learning Experimentation

## 核心问题

ML research agent 不只是写代码，还要设计实验、运行、分析结果和迭代。

## 系统设计

MLAgentBench 提供机器学习实验任务，让 agent 在真实代码环境中操作、训练和改进模型。

## 为什么重要

这是 research agent / ML experimentation agent 的重要入口。低显卡选题可以避开训练大模型，聚焦实验设计与错误分析。
