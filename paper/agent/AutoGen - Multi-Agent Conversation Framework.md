# AutoGen - Multi-Agent Conversation Framework

## 核心问题

很多 LLM 应用需要多个角色、工具和人类参与。如何把 multi-agent conversation 变成可编程框架？

## 系统设计

AutoGen 把 agent 抽象为可对话、可调用工具、可接收人类输入的实体，支持 assistant、user proxy、tool executor 等组合。

## 为什么重要

这是 multi-agent 系统论文和工程框架的核心入口。你做 research agent 时可以借鉴其 role design，但论文贡献不能只停留在“套 AutoGen”。
