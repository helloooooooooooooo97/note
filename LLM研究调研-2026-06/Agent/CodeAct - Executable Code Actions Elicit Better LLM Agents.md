# CodeAct - Executable Code Actions Elicit Better LLM Agents

## 核心问题

Agent 的 action space 怎样设计会影响能力。自然语言动作可能含糊，结构化工具调用可能受限。

## 方法

CodeAct 使用可执行代码作为 agent action，让模型通过代码表达复杂操作并获得执行反馈。

## 为什么重要

对 research agent 来说，很多动作可以代码化：搜索结果解析、frontmatter 检查、引用一致性验证、文件批量更新。
