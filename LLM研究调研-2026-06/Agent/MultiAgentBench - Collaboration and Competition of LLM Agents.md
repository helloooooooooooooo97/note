# MultiAgentBench - Collaboration and Competition of LLM Agents

## 核心问题

很多 benchmark 只测单 agent，无法评估协作、竞争、通信拓扑和群体策略。

## 关键贡献

- 多场景交互式 multi-agent benchmark。
- 同时评估任务完成和协作/竞争质量。
- 比较 star、chain、tree、graph 等协调拓扑。

## 对低显卡选题的启发

可以把多 agent 用在文献调研流程里：searcher、reader、verifier、writer、critic 分工，然后评估协作是否真的提高引用质量。
