# Optimizing Agentic Workflows using Meta-tools

## 核心问题

Agent workflow 中常有重复工具调用和低效执行模式。能否用 meta-tools 自动发现并优化？

## 方法

Agent Workflow Optimization, AWO，识别并优化冗余工具执行模式，减少 LLM 调用，同时提升成功率。

## 为什么重要

这篇很贴近“低显卡 + 方法贡献”：优化 workflow，而不是训练模型。
