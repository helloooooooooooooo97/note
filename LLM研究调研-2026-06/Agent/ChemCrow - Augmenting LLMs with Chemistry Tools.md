# ChemCrow - Augmenting LLMs with Chemistry Tools

## 核心问题

化学任务需要专业工具和数据库。LLM 如果只靠内部知识，很容易不可靠。

## 系统设计

ChemCrow 把 LLM 和化学工具集连接起来，完成合成规划、分子属性查询和化学推理任务。

## 为什么重要

这是 scientific tool agent 的代表案例，说明领域 agent 的核心是工具链、验证和专家约束。
