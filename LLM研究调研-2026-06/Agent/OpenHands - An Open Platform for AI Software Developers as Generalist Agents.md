# OpenHands - Open Platform for AI Software Developers

## 核心问题

如何构建开放、可复现、可扩展的软件开发 agent 平台，而不是只报告单个封闭系统？

## 系统设计

OpenHands 提供通用 agent runtime、工具、浏览器/终端/编辑器接口和任务评测支持。

## 为什么重要

它适合做 coding agent / generalist agent 的系统基础，也能启发研究 agent 的可复现平台设计。
