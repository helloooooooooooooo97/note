# Survey on Evaluation of LLM-based Agents

## 核心问题

LLM agent evaluation 分散在规划、工具、记忆、web、软件工程、科学 agent 等多个子方向，需要系统分类。

## 关键贡献

- 从基础能力、应用 benchmark、generalist agents、evaluation framework 等维度整理评测体系。
- 对 agent evaluation 形成较完整地图。

## 对低显卡选题的启发

适合作为开题综述入口，帮助定位“香港真实网页 research agent benchmark”属于哪一类空白。
