# WebRL - Training LLM Web Agents via Online Curriculum RL

## 核心问题

Web agent 只靠 prompt 和静态数据难以获得稳定长程决策能力，能否通过在线 RL 和自动课程学习提升？

## 方法

WebRL 使用 self-evolving online curriculum、outcome-supervised reward model 和 adaptive RL 策略训练开放 LLM web agents。

## 为什么重要

这是 agent RL 的代表路线。显卡要求较高，但它能帮助你理解“为什么低显卡方向更适合评测、修复和轻量记忆方法”。
