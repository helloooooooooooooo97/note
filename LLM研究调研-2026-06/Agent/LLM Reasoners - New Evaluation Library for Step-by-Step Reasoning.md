# LLM Reasoners - Step-by-Step Reasoning Analysis

## 核心问题

LLM agent 中的 planning 和 reasoning 往往混在一起，需要统一框架分析不同搜索/推理算法。

## 内容

论文和库整理 CoT、ToT、RAP、beam search 等 reasoning methods，并比较不同任务中的表现。

## 为什么重要

它适合用作 planner 方法综述入口，帮助你决定 research agent 是用 ReAct、ToT、LATS 还是更简单的 verifier loop。
