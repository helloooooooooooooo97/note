# AMA-Bench - Long-Horizon Memory for Agentic Applications

## 核心问题

Agent 在长期应用中需要跨会话、跨任务保存和调用记忆。单轮或短上下文评测不足。

## 关键贡献

- 长程 agent memory benchmark。
- 关注真实 agentic applications 中的 memory retrieval / update。
- 提出 AMA-Agent 作为记忆系统基线。

## 对低显卡选题的启发

很适合做 Obsidian research agent 的长期记忆研究：多天调研后，agent 是否记得之前查过的团队、论文、证据冲突。
